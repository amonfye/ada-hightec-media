# ada-hightec-media
Médias publics et file d'attente des posts Instagram @ada_hightec (ADA Hightec).
- `media/` : visuels et reels publiés via GitHub Pages
- `queue.json` : file d'attente (pending → posted)
- `scripts/make_posts.py` + `scripts/specs.json` : générateur de visuels 4:5 dans la DA ADA Hightec
